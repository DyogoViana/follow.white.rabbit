# follow.white.rabbit

Site autoral de Dyogo Viana.

Este repositório contém a implementação do site e os materiais técnicos necessários para sua publicação.

## Status

Em desenvolvimento.

O site é publicado por meio do GitHub Pages a partir da branch `main`.

## Estrutura

A estrutura do projeto será organizada conforme o desenvolvimento do site, separando:

- estrutura HTML e conteúdo;
- estilos CSS;
- comportamento e interações JavaScript;
- imagens e demais recursos visuais;
- configurações necessárias para publicação.

## Publicação

O deploy utiliza GitHub Pages com:

- Branch: `main`
- Diretório: `/ (root)`
