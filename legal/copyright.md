# Direitos autorais

Este documento complementa o arquivo `LICENSE` do repositório `follow.white.rabbit`.

## Titularidade

Salvo indicação expressa em contrário, as obras autorais disponibilizadas neste projeto são de titularidade de Dyogo Viana.

A publicação no GitHub e no GitHub Pages é feita para fins de apresentação do trabalho e não constitui autorização para reprodução, distribuição, adaptação, transformação, comercialização ou incorporação das obras em outros projetos.

## Uso não autorizado

É vedado, sem autorização prévia e expressa do titular dos direitos, entre outros usos:

- copiar ou republicar integralmente uma imagem;
- copiar parcialmente uma obra para reapresentá-la como nova;
- editar, recortar, redesenhar ou alterar elementos da obra para produzir uma versão derivada;
- remover identificação autoral ou informações de direitos;
- utilizar as obras em sites, portfólios, campanhas, produtos ou materiais comerciais;
- disponibilizar as obras para download, redistribuição ou treinamento de sistemas de IA, salvo quando houver autorização específica ou outra base legal aplicável.

Alterações visuais não eliminam, por si só, a necessidade de observar os direitos incidentes sobre a obra original e eventuais direitos morais do autor.

## Provas e versões

O projeto deve preservar, em armazenamento privado, os arquivos originais, versões intermediárias, exportações, datas de criação e demais evidências úteis para demonstrar autoria e cadeia de versões.

O histórico do Git pode funcionar como evidência auxiliar de desenvolvimento, mas não substitui eventual registro ou outras formas de prova de autoria.

## Solicitação de autorização

Pedidos de uso devem identificar claramente:

- a obra pretendida;
- a finalidade;
- onde será utilizada;
- período de utilização;
- se haverá edição, adaptação ou exploração comercial.

Nenhuma autorização deve ser presumida pela mera existência pública da obra.

## Legislação

A proteção autoral deste projeto observa a legislação brasileira aplicável, especialmente a Lei nº 9.610/1998, sem prejuízo de outras normas aplicáveis ao caso concreto.

Este documento é informativo e não substitui orientação jurídica profissional.
